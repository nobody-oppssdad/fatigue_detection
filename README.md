# fatigue_detection
使用轻量级ResNet18作为主干网络建立Faster R-CNN模型，在此基础之上调整锚框大小及宽高比使其更符合眼睛、嘴巴小目标定位要求并且加入SIoU损失进一步提高边界框回归准确性，另外还定义四种不同级别来表示不同程度疲劳情况以便于判断。
为了解决训练过程中发生梯度爆炸等问题设计稳定优化策略，使用AdamW优化器配合Warmup预热以及余弦退火学习率调整方案，同时加上梯度裁剪、早停等手段保证模型良好训练结果并且兼顾模型检测性能和训练速度。
开发基于PyQt疲劳驾驶检测仿真系统，可以在不影响驾驶员正常行驶情况下获取人脸信息并给出相应警告提示，可以应对各种复杂汽车环境，有助于保障行车安全。从实验结果来看，改进模型的平均精度为97.2%，在COCO评估标准上具有较好的检测效果，检测速度快、精度高可以实现实车环境下的检测要求，有较好的实用性和应用前景。
